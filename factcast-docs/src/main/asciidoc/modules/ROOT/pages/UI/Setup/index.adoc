= Setup
:icons: font



This section will walk you through the many options of how to setup and operate FactCast-Server-UI.

First, decide on a xref:ROOT:UI/Setup/deployment-options.adoc[deployment option] and configure the
xref:ROOT:UI/Setup/properties.adoc[necessary Vaadin property].

There are also several options regarding xref:ROOT:UI/Setup/security.adoc[security].

If you want to persist reports generated by users somewhere else than on the instance's filesystem take a look at
xref:ROOT:UI/Setup/report_storage.adoc[report storage].
